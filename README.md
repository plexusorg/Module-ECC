# Module-ECC [![Build Status](https://ci.plex.us.org/job/Module-ECC/badge/icon)](https://ci.plex.us.org/job/Module-ECC/)

Module-ECC (Extra Chat Controls) bundles NUSH raid protection and chat safety for Plex servers. NUSH protects servers from raids by new players.

Read the documentation at [plex.us.org/modules/ecc](https://plex.us.org/modules/ecc).
